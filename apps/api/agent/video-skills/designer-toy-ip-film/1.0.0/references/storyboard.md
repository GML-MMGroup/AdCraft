# 分镜指导

先用远近交替确认 collectible silhouette，再安排配件动作、角色反应和产品揭示。关键帧记录轮廓、配件握持、接触点、表情和前后状态；每次世界信息只增加一个可继续使用的钩子。

用配件交接、构图对齐或动作匹配转场，检查角色是否在切换后仍可辨认。

## Optional viewpoint clarification

Set viewing height and the toy-scale support plane before the pose. Record silhouette,
accessory ownership, contact and the visible landing or response where planned. Separate
a toy turning on its joints from the camera circling it. Scale cues and tactile material
charm matter more than filling the grid with different angles.
