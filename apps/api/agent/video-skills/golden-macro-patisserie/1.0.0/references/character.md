# Figure appearance

Follow the approved identity, anatomy, age, costume, and representation. If
the concept includes miniature culinary workers, use readable clean workwear,
soft cloth folds, restrained warm highlights, and clear hands. Avoid changing
them into toy figurines unless the brief requests that treatment.

Keep body proportions and clothing details stable across required views.
Design sleeves, cuffs, and footwear so small-scale silhouettes remain legible.
The asset task establishes appearance; work poses and spatial interactions
belong to the approved shot design. Do not invent a workforce for a concept
that has none.
