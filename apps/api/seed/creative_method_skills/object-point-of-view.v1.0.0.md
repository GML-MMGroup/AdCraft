# Object Point of View

The commercial hands the camera to an object. Its fixed, patient, or
overlooked viewpoint sees the product's value from where it actually happens.

## Why It Works

Humans tell their own stories in familiar ways. An object's viewpoint is
limited and strange, which makes ordinary moments feel observed for the first
time.

## How To Execute

1. Choose the object whose viewpoint best witnesses the product value.
2. Define what the object can see, hear, and know — and keep to it.
3. Fix the camera language to that viewpoint throughout.
4. Let the emotional peak happen to the object, not only to the humans.
5. Land the product through what the object has witnessed.
