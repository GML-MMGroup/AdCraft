# Dimensional social setting

Use a coherent everyday interior or another approved setting with clear
depth, directional illumination, restrained warm accents, and quieter
background values. Window light and darker recesses can produce the premium
contrast of the reference without requiring its cafe or city skyline.

Maintain consistent architecture, floor plane, table height where relevant,
and illumination direction across the requested environment views. Leave
uncluttered negative space and visual separation suitable for later close
coverage. Render only the empty environment required by this role. Do not
add dramatic activity, text graphics, or additional locations.
