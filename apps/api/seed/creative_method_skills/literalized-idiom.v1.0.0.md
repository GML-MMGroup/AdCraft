# Literalized Idiom

The commercial takes the audience's own words at face value. A saying that
already describes the benefit is filmed as physical fact.

## Why It Works

The audience already knows the phrase, so the idea needs no setup. Seeing it
literally is a small surprise, and the phrase becomes a verbal hook the brand
can own in conversation.

## How To Execute

1. Collect phrases the target audience already uses about the benefit.
2. Pick the one with the clearest and most filmable literal image.
3. Check that the literal image reads correctly in the target culture.
4. Show the literal image before any text names the phrase.
5. Close on the phrase so the audience leaves repeating it.

This method differs from Visual Metaphor: it starts from a phrase the audience
already says, rather than from an invented world rule.
