# 分镜指导

按材料初态、hand detail、过程变化、检查、修整和成品关系排列镜头。关键帧记录工具角度、受力点、材料边缘、碎屑、制作者视线和前后状态；每个跳转都要有因果证据。

用动作匹配、纹理接续、工具声和工作台空间连接步骤，避免只拍成品。

## Optional viewpoint clarification

Set the workbench viewpoint and contact plane before the tool, hand and material state.
Distinguish tool travel across the frame from a camera following it. Keyframes retain
input, deformation, fragments and inspection so process causality survives a cut. Choose
detail or context for the approved operation rather than requiring a fixed craft
sequence.
