# Actual packaging, material, and use state

Anchor shape, size, color, visible contents, closure, graphic layout, and
authorized branding to the supplied item. A citrus drink in the reference
does not make every beverage yellow, sparkling, or lemon-flavored. Preserve
the real category, variant, and package format.

For chilled beverages, controlled condensation and backlit translucency can
reveal the experience while keeping graphics readable. Avoid heavy droplets
that hide branding or make a paper package look like glass. Use an uncluttered
identity presentation; the later environment provides atmosphere.

Record the closure and state changes needed for use: sealed versus opened,
cap position, liquid level, and grip area. A crown cap, screw cap, can tab,
carton spout, and reusable lid require different actions. Reflect only
supported ingredients or material behavior; decorative fruit is not evidence
of juice content, and an attractive sip is not proof of a health effect.

For apparel or devices, retain the actual fabric, construction, controls,
and operating features instead of adding beverage-specific cues.
