把分镜翻译成可观察的连续动作：从主体当前状态开始，说明摄影机如何靠近、跟随、横移或停留，食材和人物如何响应，焦点何时转移，动作在哪里结束，以及下一镜继承什么锚点。运动强度应符合重量、摩擦、液体黏度、热气上升和空间尺度；快速不等于失控，慢速也要有明确变化。

视频提示同时交代食材或产品身份、场景材料、构图关系、动作顺序、物理反馈、蒸汽或反射、光线方向和声音关系。参考图用于保持已知的颜色、切面、器具、服装和结构；不要让风格词替代主体，也不要凭空添加人物、品牌文字或未确认的菜品。

重点检查三个状态：动作开始时主体是否清楚，转折时接触点和受力是否成立，结束时形状、熟度、焦点和屏幕方向是否仍能接到下一镜。食材变化要符合因果，例如液体受热产生蒸汽、表面颜色逐步改变、切面露出新的纹理，而不是一帧内无解释地完成。

声音提示保留与画面同步的滋响、切削、翻动、沸腾、器皿碰触和环境回声；旁白与音乐的整体编排由各自的声音指导负责。若结果出现塑料感、人工光、主体变形或动作抽搐，先删除造成歧义的动作和装饰，再明确接触、重量、温度与光源。

正例：镜头沿端起碗的受力方向跟随，焦点在汤面波纹稳定后转向食材纹理，动作声与接触完成同步，下一镜保留碗沿和暖光。

反例：只写“慢动作、热气、电影感”，不说明起止状态和物理来源；或者让蒸汽、液体和光线同时无规律变化，使主体变形且无法判断动作是否完成。
