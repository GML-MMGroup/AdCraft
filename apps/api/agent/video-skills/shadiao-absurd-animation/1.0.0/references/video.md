视频提示先写清画风：二维沙雕动画，粗黑描边、平涂高饱和色块、表情包式圆头小人、背景简单。再把每个笑点写成可执行的动作：规则如何崩坏、变形的过程（挤压、拉伸、冻结、压扁、弹飞）、“啵”一声回弹、角色的冷面反应特写。

花字直接由视频模型生成：每个镜头最多一句，1 到 4 个字，用引号写出原文，写清颜色、粗描边和弹出、抖动方式，例如“角色上方弹出白色粗黑描边抖动大字「透心凉」”。花字不遮挡角色面部和产品。

喜剧音效点写在对应动作上：“啵”、弹簧声、冻结声、“叮”、滑稽的坠落声、突然静音、罐头笑声。不使用明星、广告或影视作品的标志性音效和梗，背景音乐由独立配乐节点负责。

动作节奏要快而清楚，变形之间留出半拍让观众看懂；除用户产品外，画面中的包装不带真实品牌标志。

正例：小人喝下可乐瞬间冻成冰块，眼睛瞪成两个圆圈，上方弹出「透心凉」，伴随冻结声；冰块碎裂，小人弹起又摔成薄饼，“啵”地恢复，切到眯眼冷脸特写。
反例：只写“沙雕搞笑、很多变形”，没有具体的变形过程、花字原文和音效位置。
