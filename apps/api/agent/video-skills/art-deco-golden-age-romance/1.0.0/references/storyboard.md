# Storyboard viewpoint guidance

## Optional viewpoint clarification

Use the nine-panel storyboard to sample the approved scene. Set the axis, framing
distance and mirror plane before positioning the cast and product. Track approach,
crossing and handoff relative to that axis. Symmetry may remain still while a performer
moves through it; do not invent a procession or a crowd merely to fill the grid.
Preserve jewel-tone contrast and readable decorative hierarchy.
