# Anchors and controlled moving fragments

A supporting object can preserve continuity across a world change: a chair,
desk edge, cup, lamp, or other approved everyday object remains recognizable
while its surroundings transform. Choose it for a clear narrative function,
not simply because it appears in the source.

Keep construction, material, scale relationship, and visible condition stable
unless the approved rule deliberately changes them. Papers, petals, droplets,
or other fragments can make the threshold visible; their amount and direction
should clarify the transition rather than hide the central subject.

Use supporting motifs consistent with the actual category and brief. Grain
stalks, citrus, chips, sparks, and cosmetic particles are optional, not generic
decoration for every item. Avoid unapproved marks or text on supporting assets.
