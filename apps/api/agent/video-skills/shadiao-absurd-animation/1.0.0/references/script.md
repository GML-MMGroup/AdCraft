# Graphic comic timing

Translate the approved joke into readable anticipation, exaggeration and reaction.
Some beats may use squash and stretch, an abrupt transformation or a rebound;
others can use a held pose, dialogue or an ordinary product action. Preserve the
selected causal mechanism and any intentional lasting transformation.

Use a deadpan response as contrast when useful, with other expressions available
to the cast. Choose dialogue, optional captions and sound accents for meaning
and reading time. Whole-film setup and payoff need not repeat in each segment.
