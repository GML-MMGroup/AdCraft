# Official model marks

Retrieved on 2026-11-09 from the official websites below. SVG geometry is preserved;
these assets are served locally. Monochrome marks use a CSS mask to remain readable
in both picker themes. Color marks retain their original fills.

| File | Model family | Official source |
| --- | --- | --- |
| `openai.svg` | GPT / ChatGPT / Sora | [ChatGPT](https://chatgpt.com/) → [official SVG favicon](https://chatgpt.com/cdn/assets/favicon.6a33781f61.svg) |
| `zai.svg` | GLM | [Z.ai](https://z.ai/) → [official logo SVG](https://z-cdn.chatglm.cn/z-ai/static/logo.svg) |
| `bytedance.svg` | Doubao Seed / Seedance / Seedream | [ByteDance](https://www.bytedance.com/), standalone 100 × 88 SVG brand mark embedded as a data URL |
| `hailuo.svg` | MiniMax Hailuo | [Hailuo](https://hailuoai.video/), inline 32 × 32 brand mark in the sidebar home link |
| `tempolor.svg` | TemPolor | [TemPolor](https://www.tempolor.com/), inline SVG wordmark in the header home link |

Seed models use their manufacturer's official ByteDance mark. TemPolor retains
its complete official wordmark and aspect ratio instead of an invented square icon.
Routing providers such as OpenRouter, TeamoRouter and SiliconFlow do not determine
the model's brand. Unknown model families receive no guessed brand mark.
