# A neighborhood with photographic depth

Build a coherent urban route from compatible street surfaces, storefronts,
window reflections, crossings, masonry facades, and an inviting destination.
Choose the actual city or regional setting from the brief; yellow taxis, fire
escapes, and monumental stone entrances are optional reference details.

Use directional sunlight crossing cooler shade, readable depth, plausible
reflections, subdued signage, and restrained color accents. Keep facade scale,
curb height, street width, and daylight direction consistent between views.

For the required environment board, make each cell reveal useful spatial
information: approach, reverse view, facade detail, street-level depth, side
alley, window plane, overhead layout, and entrance relationship where relevant.
Vary viewpoint and scale while keeping the location recognizable. These are
environment studies; moving traffic, rising steam, and wind-touched paper can
be planned later as temporal details in footage. Do not fill the board with
near-identical front-on street compositions.
