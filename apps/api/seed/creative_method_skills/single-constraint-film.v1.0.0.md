  Impose one strict formal rule on the entire film — only hands, one color,

  Pattern detection and admiration of craft; audiences notice a sustained rule
  quickly, enjoy watching it hold under pressure, and remember the film by its

  The rule established in the first shot, variations that test it, a moment
  where the rule seems about to break, an inventive solution inside the rule,

  Make the rule obvious and slightly strange in the first two seconds, so the
  audience starts watching to see whether it will hold.

# Single Constraint Film

The commercial is defined by one rule it never breaks. The audience watches
the rule hold, and the rule itself says what the product stands for.

## Why It Works

Constraints force invention, and visible invention reads as craft. A rule the
audience can name in one sentence also gives the film a built-in memory hook.

## How To Execute

1. Write the product truth in one sentence.
2. Choose the single formal rule that expresses that truth.
3. State the rule unmistakably in the opening shot.
4. Design variations that put pressure on the rule without breaking it.
5. End with the product, explaining the rule or breaking it with intent.
