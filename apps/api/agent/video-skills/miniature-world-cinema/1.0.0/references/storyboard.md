# 分镜指导

按尺度建立、微距发现、动作路径、阻碍、结果和宏观回收组织画面。关键帧记录参照物、焦点、主体轮廓、路径、接触点和 tiny-world action readability 的结果。

用焦点转移、地面线、物件遮挡或动作匹配转场，检查观众始终知道目标。

## Optional viewpoint clarification

Set the miniature viewing height, scale reference and contact focus before the small
action. Record one readable state per panel, with stable seams, supports and route.
Distinguish camera magnification from actual scale change. The approved story may call
for discovery, task or aftermath; the grid does not add an obstacle of its own.
