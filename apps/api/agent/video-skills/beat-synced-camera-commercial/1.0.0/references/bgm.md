把音乐当作叙事能量和品牌记忆的支撑，而不是用来掩盖画面信息不足。先根据广告意图确定情绪、能量曲线、质感和听觉焦点，再安排前奏、建立、推进、峰值和收束等相对段落；段落数量和长度随内容、素材和用户目标调整。

让音乐重音与画面中的动作完成、卖点显现、视线转移或剪辑转折发生关系，但不要让每一次切换都必须卡在鼓点上。需要更高级的层次时，可用低频、打击、纹理、和声、留白和动态变化区分段落；关键卖点或对白出现时，为人声和动作声留出频谱与音量空间。

为每个重要声音事件记录进入、持续、衰减和与画面的关系。环境声建立地点，动作声证明接触和重量，音乐负责情绪与节奏；三者职责不同，避免全部同时达到峰值。转场可通过尾音、反向吸气、短暂留白、音色延续或自然环境桥接，使画面跳跃仍然可理解。

正例：产品功能显现时音乐密度上升并留出清晰的动作声，峰值后短暂收束，让品牌信息被听见。
反例：从头到尾保持同一音量和密度，或用持续强低频覆盖对白、环境和产品接触声，导致画面节奏与信息层级消失。
