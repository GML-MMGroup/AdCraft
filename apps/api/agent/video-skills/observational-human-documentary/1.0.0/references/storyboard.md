# 分镜指导

先用环境建立人物处境，再观察完整行动、停顿、调整和结果。关键帧记录人物边界、动作起止、工具、空间关系和声音来源；不要只截取最戏剧化的表情。

用环境声、视线、动作匹配和空间转向连接段落。检查每个旁白落点是否有事实依据。

## Optional viewpoint clarification

Set a respectful observation distance before recording the subject's real action,
hesitation or adjustment. Preserve tool ownership, start and end states and sound
sources. Use a closer view only when it explains a detail. The nine-panel selection
should retain human context rather than invent dramatic poses for camera variety.
