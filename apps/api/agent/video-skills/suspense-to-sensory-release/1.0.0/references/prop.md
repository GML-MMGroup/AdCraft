# Supporting objects

Give each approved prop an ordinary material identity with readable edges,
contact surfaces, and wear appropriate to its setting. Muted surroundings
can isolate a significant switch, cup, document, or device without making
all props sinister. Avoid additional medical tools or occult decoration.

If an object is a clue, preserve its shape and distinguishing detail between
the setup and reveal. Clean reference views show the whole prop; selective
concealment is a storyboard choice. Supporting objects should not visually compete with
the hero product or add an unsupported capability through their design.
