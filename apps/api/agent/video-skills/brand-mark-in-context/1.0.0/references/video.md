# 视频指导

镜头运动先服务产品与人物，再在适当时机让 brand-shape echoes 清楚出现。保持标志比例、透视、光线和材质，避免漂浮、扭曲或反复闪现。

声音可用产品动作、环境回声和品牌落点的简洁声学标记，但不要让声音替代视觉识别。

## Optional shot phrasing

Use viewpoint-first wording for an approved alignment reveal: "From a held oblique view,
the foreground edge clears toward screen-left, exposing the existing shape behind it."
If the camera moves instead, name its path and keep the object still. Brand-shape echoes
may also emerge through a match cut; do not convert graphic recognition into mandatory
object rotation or a floating logo.
