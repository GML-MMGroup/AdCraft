# Sincere characters for comic contrast

Develop the approved identity and wardrobe with believable photographic materials.
Ordinary or unusually formal presentation can contrast with an absurd event.
Keep a composed default expression when appropriate; a witness may be expressive
and the protagonist may react when the story needs it. Reference-sheet expression
does not fix performance throughout the film. Preserve authorized appearance and
wardrobe details rather than adding a generic comic costume.
