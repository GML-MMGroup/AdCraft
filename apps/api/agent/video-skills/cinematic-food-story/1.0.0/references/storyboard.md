用“镜头目的—食材或人物动作—摄影机关系—质地证据—声音事件—出入镜锚点”组织分镜。先安排观察、积累、转折和 appetite-led reveal 的信息递进，再选择微距、近景、中景或环境镜头。每个镜头都要说明观众此刻应看见的变化，以及它如何推动下一镜。

把每个关键帧的状态写成开始、变化中段和结束三部分：食材的形状与温度，手或器具的接触点，蒸汽和液体的方向，焦点与光线，动作声的进入和衰减。相邻镜头至少共享一个可继承锚点，例如切面、勺子的运动方向、盘沿、蒸汽形状、色彩或声音尾音。

转场优先使用动势匹配、物理遮挡、形状呼应和声音桥接。处理动作可以轻柔而有力量，但不要用无依据的破碎、爆炸或剧烈飞散制造刺激；自然的切片、搅拌、翻面和倾倒要保持连续、可解释的受力关系。复杂信息段落减少同时变化的维度，情绪高点只增加真正有意义的变化。

音频标注旁白、环境底噪、器具声、处理声、沸腾或咬合前后的停顿，并说明它们与画面动作的关系。音乐不应遮住关键物理声。纯环境镜头保留地点和空气感，人物镜头明确谁在看、谁先动以及食物如何仍是叙事中心。

正例：先用稳定构图建立台面，再沿勺子的旋转切入汤汁纹理，蒸汽遮挡带到摆盘，最后用同一色彩锚点回到完整菜品。

反例：只罗列景别和运镜名称，没有开始与结束状态；或相邻镜头同时改变食材熟度、空间轴线、光源和声音，造成无法修复的连续性断裂。
