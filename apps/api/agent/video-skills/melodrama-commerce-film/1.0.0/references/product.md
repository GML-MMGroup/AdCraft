# Hero item identity and surface

Render the supplied item with stable silhouette, scale, finish, color, closure,
and authorized branding. Separate its outer contour with directional light
and gentle edge highlights. Preserve useful material detail without glare
obscuring the feature or flattening the packaging.

Create the clean product asset required by the current output contract.
Dramatic handling, visible use, and sales gestures belong to later scene
coverage, not this isolated asset. Do not pre-damage it to suggest the plot.
Avoid inventing accessories, variant colors, certification marks, or feature
graphics. The visual hierarchy should survive both a brief insert and a
longer closing hero display, regardless of product category.
