# Visual Metaphor

The commercial invents one physical law for the world, and that law is the
product value made visible.

## Why It Works

The audience must be able to answer one question: why does this strange rule
belong to this product? When the answer is clear, the metaphor becomes the
product's most ownable asset.

## How To Execute

1. State the abstract value in one word.
2. Invent the world rule that expresses it physically.
3. Let the rule operate before any product appears.
4. Connect the rule to the product at the escalation point.
5. Test the one-question answer before production.
