# 视频指导

让变形有起因、过程、阻力和结果，先保持核心轮廓，再加入伸展、折叠、膨胀或转化。impossible scale 需要视差、接触和人物反应，不能只靠镜头推近。

声音可用物体摩擦、弹性、空间回声和色彩变化对应的短促音色。结果只剩奇观时减少效果，恢复规则和功能。

## Optional shot phrasing

For an approved scale change, "A fixed wide view retains the reference object while the
hero expands beside it" communicates impossible scale more clearly than an ambiguous
push-in. If the camera also moves, describe its path separately from transformation.
Keep pop color and bold object transformation, including deliberate graphic cuts; the
technique must not flatten the concept into conventional realism.
