# 视频指导

先保持空间稳定和运动方向清晰，再加入缓慢推进、升降或横移。vast scale 需要前景参照和远景视差；不要用剧烈镜头运动代替尺度。设备、服装、接口和光源在动作前后保持连续。

声音可用低频环境、脚步、机械反馈和开阔回声建立深度，功能确认时保留清楚的动作声。结果失去极简秩序时，删减粒子和动态元素，恢复几何锚点。

## Optional shot phrasing

For an approved approach, "A locked wide view holds the foreground scale marker while
the subject recedes toward the distant opening" can convey vast scale without camera
travel. If a slow rise or track is selected, put its path before the concurrent action
and retain parallax anchors. Preserve monumental stillness, geometry and mechanical
feedback rather than adding motion simply because the tutorial demonstrates it.
