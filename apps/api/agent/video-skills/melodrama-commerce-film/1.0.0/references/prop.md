# Supporting object readability

Keep supporting objects simpler and less visually dominant than the hero
item. Use a coherent restrained palette, recognizable outlines, and believable
material wear. A contrasting shape or color may clarify a comparison only
when the approved brief includes one.

Preserve the requested asset isolation and exact prop identity. The source's
drink glass, cafe furniture, and liquid are optional story-specific objects.
Do not add them automatically or reproduce unrelated branding.
