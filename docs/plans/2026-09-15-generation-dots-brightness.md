# 生成态节点点阵亮度调整方案

## 目标

提高节点卡片生成态双层点阵中白色动态光斑的可见度，让用户在生成过程中更容易识别“正在工作”，同时保持现有点阵形变、呼吸节奏、卡片尺寸和画布性能不变。

## 设计决定

- 这是频繁出现的状态指示（state indication），不增加新的运动或闪烁。
- 只调整动态白色点阵的亮度曲线：提高呼吸动画的不透明度上限和下限，并同步提高 reduced-motion 的静态亮度。
- 不修改 mask 的形变路径、6.4 秒移动周期、2.4 秒呼吸周期、点阵尺寸、背景色或交互暂停逻辑。
- 继续使用 CSS opacity 动画，不引入 JS 定时器、逐帧更新或额外网络请求；`prefers-reduced-motion` 保持静态亮点。
- 静态底层点阵保持原强度，避免整个生成区域变成一块刺眼白面；“白色区域”仅指动态光斑层。

## 实施步骤

1. 在 `AgentCanvasNode.css` 将动态点阵呼吸曲线从 `0.62 → 0.88` 提升为 `0.76 → 1`。
2. 将 reduced-motion 下动态点阵的静态 opacity 从 `0.7` 提升为 `0.86`。
3. 更新 CSS 合同测试，锁定亮度范围与原有轨迹/周期不变。
4. 运行 canvas 节点单测、相关 workbench 回归、typecheck、lint 和 diff 检查。

## 验收标准

- 生成态中央白色光斑比现状更清晰，但不改变位置、大小或移动轨迹。
- 生成态动画仍能在画布交互时暂停，减少动态效果时无动画且保持更亮的静态光斑。
- 不产生布局位移、额外渲染请求或 JS 定时器。

本方案在独立 worktree 实施，完成后再根据用户指示合并到本地 `main`。
