# Misdirection and Reversal

The commercial is a controlled misreading. The viewer is invited to be wrong,
confidently, and the correction is where the product lives.

## Why It Works

Surprise alone fades; surprise that clarifies value converts. The reversal
must make the product more necessary, not merely more visible.

## How To Execute

1. Choose the expectation the viewer will confidently hold.
2. Reinforce it at least twice before the break.
3. Plant the anomalous detail where rewatching rewards attention.
4. Execute the reversal at the latest point the story allows.
5. Reinterpret at least one earlier scene so the twist reaches backwards.
