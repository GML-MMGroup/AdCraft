# Noto Sans SC for the brand decision panel

Noto Sans SC is the Google Fonts distribution of the Source Han Sans design.
Downloaded from the Google Fonts CSS API on 2026-11-02 (release v41), with
variable weights 400–600. See OFL.txt for the SIL Open Font License 1.1.

The original Unicode ranges are preserved in src/styles/brand-chinese-font.css.
Browsers load only the WOFF2 subsets needed for visible text. The private family
name "AdCraft Brand Sans SC" scopes use to the brand decision panel; Latin text
continues to use Manrope. No external font requests are needed at runtime.

Source: https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400..600&display=swap
