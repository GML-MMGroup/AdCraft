# 分镜指导

为每个节拍画出准备、爆发、拖尾、落点和恢复关键帧。记录角色锚点、主运动线、色块方向、镜头视点和道具接触。变形强度应随能量曲线变化，而不是持续最大化。

用形状匹配、线条延展、色块擦过或动作方向转场，检查落点是否可读。

## Optional viewpoint clarification

Set the graphic viewing plane and main motion line before preparation, impact, smear and
recovery states. Separate a viewport pan from character stretch or color-driven motion.
Keyframes retain identity anchors, contact and the readable landing; strong deformation
need not appear in every panel.
