# Product material identity

Preserve the supplied silhouette, proportions, ingredient count, layer order,
cut surface, and approved artwork. For food, separate dry flaky crust, soft
cream, fruit skin, and any specified glaze. Do not add fillings, sugar,
berries, or a glossy coating merely because the reference contains them.

Use restrained warm side lighting to describe surface relief. Keep shadow
information in dark ingredients and prevent white fillings from turning
orange. Favor crisp edge detail over a uniform sharpness filter.

For an identity asset, retain the isolated presentation and background
required by the current capability. Describe the unchanged object clearly
enough for later views to preserve the same structure and materials.
