# 首页字体配置导出设计

**日期：** 2026-07-30
**状态：** 已确认，待实施

## 目标

在首页字体调试工作台中提供一次性 JSON 导出能力。用户调整完成后，可下载当前
九个排版区域的完整配置文件，用于留存和分享。

## 范围

- 只增加 JSON 导出。
- 导出当前 `settings` 状态中的完整九个区域配置。
- 每个区域完整保留字体、字重、样式、字号、行高、字距和大小写设置。
- 文件名包含导出时间，避免浏览器下载同名文件时难以识别。
- 导出失败时在控制面板显示简短文本提示。

## 非目标

- 不提供导入功能。
- 不增加后端接口、数据库、本地持久化或用户账户数据。
- 不改变正式主页、全局主题或字体调试功能本身。
- 不在导出内容中加入 API 配置、页面截图、临时菜单状态或面板折叠状态。

## 交互设计

下载按钮位于字体调试面板标题区，使用下载图标，并提供 `Export configuration`
悬浮提示和无障碍名称。点击后立即下载 JSON；成功不额外打断用户操作。若浏览器
无法创建下载链接，则显示轻量错误文本。

## 数据格式

下载文件直接序列化当前 `settings` 对象，不添加版本、导出时间等 JSON 元数据。
导出时间只用于文件名。文件结构固定为九个区域键，各区域值均为完整的
`TypographyRegionSettings` 对象。

```json
{
  "heroMain": {
    "fontId": "instrument-serif",
    "fontWeight": 400,
    "fontStyle": "normal",
    "fontSizePx": 64,
    "lineHeight": 1.15,
    "letterSpacingEm": 0.012,
    "textTransform": "none"
  }
}
```

## 技术方案

前端新增一个独立导出工具：将 `settings` 通过 `JSON.stringify(settings, null, 2)`
转为 UTF-8 JSON 文本，创建 `application/json` 类型的 `Blob`，再使用临时对象 URL
和隐藏锚点触发浏览器下载。下载触发后立即移除锚点并释放对象 URL。浏览器下载能力
不可用或创建对象 URL 抛错时，工具抛出错误，由页面捕获并显示提示。

## 验收标准

- 点击导出按钮会下载一个 `.json` 文件。
- 文件解析后的值与当前完整 `settings` 状态完全相等。
- 文件名包含 `adcraft-home-typography-` 前缀和导出日期。
- 下载 API 异常时显示明确但简短的失败提示。
- 现有字体选择、重置和深色主题行为保持可用。
