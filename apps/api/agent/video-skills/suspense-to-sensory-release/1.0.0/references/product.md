# Product material and recognition

Keep the supplied silhouette, components, packaging, labels, interface, and
brand colors authoritative. Separate surfaces according to actual material:
fabric has fibers and compression, brushed metal has directional highlights,
liquid has plausible viscosity, and an interface has readable visual states.
No universal food gloss, condensation, steam, or red-orange palette.

Make the product reference complete and clearly lit so it can support later
shots. Narrative concealment belongs to shot framing, not a damaged or
unrecognizable reference asset. Reveal imagery should emphasize the surface
or interaction that demonstrates the agreed benefit. A service can use its
approved interface or use context instead of an invented package.
