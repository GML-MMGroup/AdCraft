# 视频指导

让变化沿角色轮廓、关节和道具路径发生，先确保脸、服装和身份可读，再增加光带、粒子和镜面闪光。A heroic reveal may use the approved action or a held pose; choose emphasis without adding an unapproved rescue or task.

声音分层使用道具触发、能量聚集、服装展开、脚步和结果反馈。效果过满时删减光效，恢复 transformation grammar。

## Optional shot phrasing

For a planned transformation, "A held frontal animated view keeps the silhouette
centered while the light trail follows the existing prop path" anchors change without
losing identity. If an orbit is intended, name its path separately from any body
rotation. Keep transformation grammar and rhythmic graphic cuts; camera-first wording
does not mandate a spin, photorealism or an extra heroic action.
