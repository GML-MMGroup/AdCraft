# 分镜指导

按等待、观察、错过、追赶、相遇或回望组织 youthful longing。关键帧记录视线、手中物件、天气接触、脚步方向和 sky and city transitions 的连接点。

用玻璃反射、仰视、楼群遮挡、同向移动或灯光变化转场；检查情绪是否由动作推进。

## Optional viewpoint clarification

Define the animated viewpoint, gaze line and weather plane before the small emotional
action. Track the relevant object and movement direction through sky and city
transitions. A held window view can contain wind or rain without moving the camera. The
approved relationship determines which moment is seen, not a compulsory meeting or
chase.
