# Consultation room and insert environments

Use the approved consultation-room architecture with readable wall planes,
entry position, windows and practical light sources. Cool neutral surfaces,
muted furnishings and controlled negative space support a contained mood.
Keep floor space and depth understandable across all requested environment
views; vary viewpoint meaningfully while preserving the same room geometry.

Provide enough ambient fill to retain surface texture. A later lighter mood
can use the same layout with softer contrast or more open framing; a new
location, warm palette or bright clinical white is not required. Environment
reference views remain spatially informative instead of becoming dark film stills.

When tasked with an approved external insert or closing environment, use its actual
location brief instead of repeating the clinic. Establish recognizable spatial
context, believable scale, usable support surfaces and motivated lighting.
Keep those cues readable without excessive background blur. Preserve clean
negative space for the finishing composition where requested. Keep external
views distinct from the consultation-room geography, which stays stable for
the return. Environmental references describe the setting; shot timing belongs
to the storyboard and video roles.
