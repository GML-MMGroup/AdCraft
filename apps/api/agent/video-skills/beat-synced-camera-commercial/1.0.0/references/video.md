把分镜意图翻译成可观察的连续动作：说明摄影机从哪里开始、如何移动、主体如何响应、焦点何时转移、动作在哪里结束，以及下一镜如何承接。优先使用有动机的推近、横移、环绕、跟随、升降或静止观察；运动曲线要符合主体重量、接触面、惯性和空间尺度。快速不等于混乱，强烈不等于失去主体。

视频提示应同时交代主体身份与服装、场景锚点、构图关系、动作顺序、镜头运动、焦点变化、光线和连续性约束。参考图用于锁定已知身份、结构、材质和服装；参考视频只在确有空间或动作承接价值时使用。不要用风格词替代主体描述，也不要加入未经确认的新人物、道具或背景事件。

关键帧至少检查开始、动作转折和结束三个状态：主体是否仍可辨认，接触点是否合理，视线和屏幕方向是否连续，焦点是否按意图移动。生成结果偏移时，优先指出具体偏移并减少歧义；不要通过降低主体一致性来换取运动强度。

声音与画面同步时，标记动作声、接触声、环境底噪、对白或旁白的进入和退出关系。声音重音可以强化剪辑点，但背景音乐的曲式、配器和动态由独立的声音指导负责；视频指导只保留与画面动作同步的声音线索。

正例：镜头从产品侧面开始，沿手部拿起产品的方向平稳跟随，焦点在接触完成时转到功能部件，动作声与切点一致，下一镜保留相同受力方向。
反例：只写“高速旋转、震撼卡点”，没有起止状态、主体动作或空间依据，结果导致主体变形、方向跳变和声音错位。
