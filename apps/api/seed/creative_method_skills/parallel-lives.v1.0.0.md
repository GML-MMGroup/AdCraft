# Parallel Lives

The commercial shows two lives at once. The audience watches them separate
and decides for themselves which side they want to be on.

## Why It Works

Comparison is persuasive when the audience does it. Parallel structure makes
the product's effect visible as a difference rather than a claim.

## How To Execute

1. Define a single, product-driven point of divergence.
2. Make both starting points identical and believable.
3. Cut both paths with matched framing and rhythm.
4. Let the difference grow gradually, then become undeniable.
5. End with a clear contrast or a reconnection that lands the product.
