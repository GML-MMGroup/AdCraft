# 视频指导

让主观变化从触碰、视线、呼吸、镜面、声音或光线开始，逐步改变材质和空间。graphic match cuts 需要保持形状或运动连续，不能靠快速闪烁掩盖缺少因果。

声音用重复旋律、空间回声、近距离呼吸和现实环境的差异区分层次。结果迷失时先减少现实层和特效。

## Optional shot phrasing

Where a planned transformation shares a gesture, write "In a held subjective close view,
the hand completes its touch while the surface changes around the same outline." A
graphic match cut should be named as a cut, not disguised as continuous camera travel.
Camera-relative wording clarifies motion within a reality layer; it must preserve
intentional subjective transitions and identity motifs.
