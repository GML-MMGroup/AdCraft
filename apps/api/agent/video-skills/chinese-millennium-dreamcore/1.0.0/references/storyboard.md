# 分镜指导

按熟悉空间、重复路径、记忆碎片、异常发现和现实回收组织镜头。关键帧记录物件、视线、路径、屏幕状态、色彩和声音回声；碎片之间至少保留一个身份或空间锚点。

用反射、屏幕擦除、重复构图、局部遮挡或声音桥接转场，避免随机闪断。

## Optional viewpoint clarification

Anchor a remembered viewpoint, corridor edge or screen plane before describing the
anomaly within it. Repeated frames should expose a meaningful changed detail, not
accidentally relocate the subject. Mark intentional discontinuities as memory cuts and
retain a spatial or identity cue. Nostalgic digital texture does not require every panel
to wobble.
