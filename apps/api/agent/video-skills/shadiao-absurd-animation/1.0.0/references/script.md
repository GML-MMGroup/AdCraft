按“离谱钩子、夸张变形、回弹、更离谱的变形、冷面收尾”组织剧本。第一个画面就是规则崩坏的结果，之后每段只崩坏一条新规则，并写清角色怎样若无其事地接受它。

每个段落写明：崩坏的规则、角色的动作、变形和回弹的过程、冷面反应、可选的短花字原文（1 到 4 个字）和喜剧音效点。产品是规则崩坏的起因，结尾角色若无其事地继续使用产品。

台词极少，必要时用一句一本正经的短台词或旁白；不使用明星、网红或影视作品的原句。

正例：小人喝一口冰可乐，全身冻成冰块，花字「透心凉」，冰块碎裂后小人弹到天上，摔回地面变成薄饼，再“啵”地恢复，面无表情继续喝。
反例：一段接一段的随机变形，没有起因、没有升级，也没有冷面落点。
