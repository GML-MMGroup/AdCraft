# Graphic key states in the nine-panel grid

Sample the approved local sequence in exactly nine ordered, text-free panels.
Use silhouette, contour and color to clarify action. For a planned deformation,
choose the preparation, expressive extreme and resulting state needed to read it.
A held reaction or ordinary product action can occupy other panels.

Cast design follows the approved identities; a large round face is an optional
reaction treatment. Keep the output medium consistent and preserve deliberate
state changes. Opening gags and final payoffs belong where the whole story places
them, not automatically in the first and last cell of every grid. Carry captions,
sound and finishing instructions separately from generated panel imagery.
