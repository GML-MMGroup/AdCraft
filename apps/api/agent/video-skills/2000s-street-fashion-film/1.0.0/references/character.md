# Independent model identities and looks

Model count is variable. Use the approved brief and cast references to establish
one, two, or more distinct identities; image-file count is not head count.
One photograph can contain several models, and several photographs can depict
the same model. Keep each identity's face or head features, hair, proportions,
wardrobe, and accessories attached to that identity.

Capture the supplied look before adding period styling. The reference's leather
outerwear, denim, boots, and small bags are examples, not a uniform. Adapt
makeup, hair movement, layers, and silhouette only within the approved styling.
Use natural balance and a relaxed editorial attitude rather than a frozen
runway pose in every view.

Create clear identity references in the requested asset format. Multiple
angles depict the same model, while different approved models remain separate.
Human-face rendering follows the current image contract; this skill adds no
universal illustration requirement. The final photographic performance can
include confidence, curiosity, a fleeting smile, or a shared glance as the
approved beat requires.
