# Tool and accessory design

Choose clean, functional forms with a restrained handcrafted finish: fine
metal mesh, a narrow wooden handle, a stable ladder, or a culinary brush when
specified. Preserve the approved tool type and dimensions; do not introduce
culinary equipment into an unrelated brief.

Show credible mesh spacing, handle thickness, bristles, joints, and contact
surfaces. Separate wood from brushed metal with roughness and edge highlights.
Keep the silhouette readable at its intended scale, without decorative detail
that obscures how the tool works. Use the isolated presentation required by
the current asset task.
