用“镜头目的 → 主体动作 → 摄影机动作 → 构图锚点 → 声音关系 → 出入镜连接”设计每个镜头。先安排信息和情绪的递进，再选择景别、机位、镜头轴线和运动曲线；不要先堆运镜名称再寻找意义。节奏重音应落在动作完成、视线转移、卖点显现或叙事转折等可观察事件上。

为每个关键镜头记录起始、变化中段和结束状态。关键帧不只描述位置，也描述主体姿态、视线、手部或道具关系、焦点、光线和声音进入点。镜头之间至少保留一个可继承的锚点，例如主体轮廓、运动方向、视线落点、空间边缘或光源；若要故意跳轴或改变景别，先用动作、遮挡、视线或声音给出过渡理由。

连续性检查包括：人物身份和服装、产品结构、场景布局、前后景层次、屏幕方向、动作相位、接触关系、光影和天气。多人物场景还要明确谁在看谁、谁先动、画面左右关系如何保持。纯场景镜头不要无理由引入人物；人物镜头也不要让场景细节吞没叙事主体。

根据素材和目标选择节奏密度：信息复杂时减少同时变化的维度，情绪高点时允许更密集的切换，但保留一个稳定锚点。用相对段落和事件顺序表达节奏，不写死输出规格、固定时轴或固定流程。

正例：先用稳定构图交代空间，再以人物转身引导镜头横移，动作结束时切到产品细节，下一镜从同一方向接续。
反例：相邻镜头同时改变轴线、主体身份、焦点和光源，或只写“快速、震撼、电影感”而没有可执行的动作与起止状态。
