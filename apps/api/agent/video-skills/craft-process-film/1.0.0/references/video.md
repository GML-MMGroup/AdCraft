# 视频指导

镜头优先呈现手部握持、工具角度、受力、材料响应和检查动作。material transformation 要有连续输入与输出，保持碎屑、划痕、温度、湿度和光线状态；不要用加速或模糊遮盖断裂。

声音使用切削、敲击、摩擦、机器、呼吸和工作室底噪，节奏跟随 maker-focused pacing。

## Optional shot phrasing

For a tool pass, "A locked oblique close-up holds the contact plane as the tool travels
toward screen-right and shavings collect behind it" binds observation to transformation.
If following is necessary, name the track before the pass. Retain pauses for maker
judgment, real resistance and tool sound. Camera movement should not obscure the very
contact that proves the process.
